# ♟️ Chess

A web-based chess game built as a learning project around browser-based chess functionality.

## ✨ Overview

This repository contains a lightweight chess implementation using JavaScript and [`chess.js`](https://github.com/jhlywa/chess.js) for chess rules and game-state handling.

## 🛠️ Tech Stack

- JavaScript
- HTML / CSS
- [chess.js](https://github.com/jhlywa/chess.js)

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/l0gicb0x/Chess.git
cd Chess
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project

Open the frontend in your browser using your preferred local development server.

## 🎯 Project Goals

- Explore how chess rules and game state can be represented in JavaScript
- Build a browser-based chess experience
- Experiment with interactive game logic and UI development

## 📌 Status

This is an evolving project and can be extended with features such as multiplayer support, move history, timers, check/checkmate UI, and a stronger game interface.
